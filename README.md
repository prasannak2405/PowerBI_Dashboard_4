# 👔 Fashion Sales Analysis 

## 📌 Project Overview
This project analyzes **Fashion sales on men’s clothing sales data** using **Microsoft Power BI** to understand sales performance, product trends, and customer behavior.  
The dataset is sourced from an **Azure SQL Database** and visualized through an interactive Power BI dashboard.

---

## 🗄️ Data Source
- **Database**: Azure SQL Database  
- **Dataset**: Men’s clothing sales data  
- Connected to Power BI via **Microsoft SQL Server**

---

## 🔍 Data Understanding & Preparation
- Initial data understanding and exploratory analysis
- Data transformation and data cleaning using **Power Query Editor**
- Handling missing values and inconsistent data
- Creation of derived fields to support analysis

---

## 🔗 Azure SQL to Power BI Integration
- Connected **Azure SQL Database** to Power BI using Microsoft SQL Server
- Imported and modeled data for reporting
- Ensured efficient data refresh and query performance

---

## 📐 DAX Functions Used 
- `DIVIDE()` – safe division for ratio and percentage calculations  
- `RANDBETWEEN()` – generation of random values for analytical scenarios  

---

## 🧮 Calculated Columns
- Added calculated columns to enhance sales and product analysis
- Created custom fields for categorization and comparison

---

## 📊 Visualizations
- Sales performance visuals by product and category
- Use of **Scroller visuals** added from **Power BI App Source**
- Interactive dashboard for easy exploration of trends

---

## 📈 Key Insights
- Identification of top-performing men’s clothing categories
- Sales contribution analysis across products
- Trend visibility using interactive visuals and scrollers
- Improved understanding of customer purchase patterns
